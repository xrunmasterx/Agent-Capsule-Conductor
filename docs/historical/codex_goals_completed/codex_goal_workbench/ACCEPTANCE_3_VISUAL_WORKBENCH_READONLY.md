# Acceptance: Phase 2C Visual Workbench Read-only MVP

Phase 2C is complete only after Phase 2B is complete.

## 1. UI can start

The web app should start with the configured package manager.

Example:

```bash
cd web
npm install
npm run dev
```

Exact commands may vary, but they must be documented.

## 2. Required pages exist

- Run List
- Run Inspector
- Capsule Browser
- Artifact Viewer
- Workflow Viewer

## 3. Read-only constraint

The UI must not provide:

- workflow save,
- drag-and-drop editing save,
- edge editing save,
- direct mutation of capsules,
- direct mutation of workflow YAML.

## 4. Data source

The UI must read data from `acc-server` API, not by directly parsing local files.

## 5. Fixture run can be inspected

The UI must be able to inspect a real or fixture run generated by:

```bash
uv run acc run fake-agent.generic \
  --input capsules/fake-agent.generic/examples/input.json \
  --run-dir runs/ui_acceptance_fake \
  --emit-conductor-json
```

## 6. Tests

At minimum:

```bash
npm test
```

or the equivalent configured UI test command must pass.
